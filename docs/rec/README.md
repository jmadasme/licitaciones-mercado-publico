# rec/ — video explicativo

Este directorio contiene el video asciinema de **Licitaciones Mercado Público** y el reproductor
que se usa en la página del proyecto.

- `licitaciones-mercado-publico.cast`: grabación original (asciicast v2).
- `licitaciones-mercado-publico.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 2:53. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
